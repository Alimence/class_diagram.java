# Student Class Diagram – Java Implementation

## Project Description
This project demonstrates how to transform a UML Student Class Diagram into Java code using Object-Oriented Programming (OOP) principles.

## Project Objectives
- Understand the structure of a UML class diagram.
- Identify classes, attributes, and methods.
- Convert the class diagram into Java code.
- Create Student objects using the Student class.
- Demonstrate how objects interact with class methods.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Git and GitHub

## Learning Outcome
This project helps demonstrate the relationship between UML class diagrams and their implementation in Java, providing practical experience in object-oriented software development.
